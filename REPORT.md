# Отчёт по практике: управление зависимостями с Poetry

## 1. Конфигурация проекта

- Python: 3.12
- Виртуальное окружение: `.venv`
- Локальная настройка окружения: `poetry.toml`
- Файл конфигурации зависимостей: `pyproject.toml`
- Файл фиксации версий: `poetry.lock`

## 2. Зависимости

### Основные (main)
- requests — HTTP-запросы к API
- pandas — обработка данных
- matplotlib — построение графиков

### Тестирование (test)
- pytest — запуск автоматических тестов

### Разработка (dev)
- ruff — проверка и автоматическое исправление кода

## 3. Программа

Скрипт `plt_temp.py` получает почасовой прогноз температуры из Open-Meteo для Москвы, формирует DataFrame, сортирует данные по времени, сохраняет CSV и строит график PNG.

В программе предусмотрены:
- тайм-аут HTTP-запроса;
- проверка HTTP-статуса ответа;
- отдельная функция подготовки DataFrame;
- сохранение данных за 24 часа;
- сохранение графика в PNG.
